# Personal Website

This is the source code for my personal website, built to showcase my professional background, projects, and contact information. The site is fully static, written in **HTML** and **CSS**, and designed with **responsive scaling** for dynamic resolution compatibility across devices.

### 🌐 Live Site
Hosted via **GitHub Pages** — [Visit Website](https://rygelyance.github.io)

### 📄 Site Features
- **About Me**: A brief personal introduction and overview of my professional interests.
- **Contact Information**: Direct links to my email, LinkedIn, and other relevant platforms.
- **Project Showcase**: A table featuring several recent projects, including descriptions and links where applicable.
- **Responsive Design**: Layout adapts smoothly to different screen sizes and resolutions.

### 🚀 Technologies Used
- HTML5
- CSS3
- GitHub Pages
